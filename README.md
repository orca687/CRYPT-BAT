# CRYPT-BAT
CRYPT-BAT is a desktop application developed with Python, featuring Morse Code encoding and decoding, as well as image steganography.
✨ Features

1. Morse Code

Encode text into Morse code.

Decode Morse code into readable text.

Supports English letters and numbers.

Includes a custom Morse code mapping for Persian characters.

Uses . and - for standard Morse code and * and ? for the custom Persian mapping.

2. Steganography

Hide secret text messages inside images.

Extract hidden messages from encoded images.

Supports image-based steganography using LSB techniques.
